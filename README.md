# Zapshop Garage MVP

Flutter MVP-приложение Zapshop Garage: гараж, история обслуживания, маркет запчастей Zapshop, избранное/корзина/заявки и AI-помощник.

## Установка и запуск приложения
1. Установите Flutter SDK (stable 3.3+).
2. Откройте проект в VS Code.
3. Выполните:
   ```bash
   flutter pub get
   flutter run
   ```

## Маркет API (реальный)
Base URL: `https://zapshop.by/wp-json/pmm/v1`

Используемые endpoints:
- `GET /parts`
- `GET /parts/match-car`
- `GET /parts/{id}`
- `POST /requests`

## Полноценная система AI-ключа и AI+Фото

### Важно
OpenAI API key **нельзя хранить в мобильном приложении**. Ключ должен быть только на backend proxy.

### Что реализовано в проекте
- В приложении реализованы режимы AI:
  - Mock AI (без ключа)
  - Backend AI Proxy (реальный)
- В AI-экране есть настройки:
  - включить/выключить proxy
  - задать Base URL proxy
- Поддержана отправка фото в AI (через backend proxy).

### Backend proxy (в папке `backend/`)
Добавлен готовый Node.js proxy:
- `POST /api/ai/chat`
- принимает:
  - `message`
  - `image_base64` (опционально)
- вызывает OpenAI Responses API

#### Запуск backend proxy
1. Перейдите в папку backend:
   ```bash
   cd backend
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте `.env` из шаблона:
   ```bash
   cp .env.example .env
   ```
4. В `.env` укажите реальный ключ:
   ```env
   OPENAI_API_KEY=sk-...
   PORT=8080
   ```
5. Запустите сервер:
   ```bash
   npm run dev
   ```

По умолчанию в Android emulator для локального backend используется URL:
`http://10.0.2.2:8080`

Проверьте здоровье proxy:
```bash
curl http://localhost:8080/health
```
Если AI отвечает шаблонно, убедитесь что в AI экране включен режим `Backend AI Proxy`, а не `Mock AI`.

## Что реализовано в MVP
- Нижняя навигация: Главная / Гараж / Маркет / AI / Профиль.
- Hive-локальное хранение (cars, services, favorites, cart, requests, profile).
- Гараж + история обслуживания.
- Маркет с реальным API Zapshop.
- Поиск, infinite scroll, фильтр под активное авто.
- Карточка товара, заявки, избранное, корзина.
- AI-помощник с текстом + фото и переключаемым proxy/mock режимом.
- Premium UI улучшения: обновленная dark-тема, быстрые действия на главной, category chips + сортировка + pull-to-refresh в маркете, fallback для битых фото.
